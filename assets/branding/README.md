# appshell branding

| File                      | Use                                                        |
| ------------------------- | ---------------------------------------------------------- |
| `appshell-logo.svg`       | The logo, for light backgrounds                            |
| `appshell-logo-white.svg` | The logo, for dark backgrounds                             |
| `appshell-logo-blue.svg`  | The logo, in blue                                          |
| `appshell-mark.svg`       | The cube alone, on a square canvas, for icons and favicons |
| `appshell-logo*_2x.png`   | The logos as images, for the READMEs' headers              |

## Space around the logo

The logos are trimmed to their artwork: the cube's left edge is the file's left edge, and its top
and bottom are the file's. So a logo drawn 40px tall is 40px of artwork, and its left edge lines
up with whatever the layout aligns it to, such as a navigation's icons or a heading's first letter.
The space around it is the layout's to give: at least a quarter of the logo's height on every side,
such as 10px around one drawn 40px tall.

The mark keeps its square canvas, with room around the cube: an icon is drawn in a box the
platform sets, and the room keeps the cube clear of the box's edge or a rounded mask.
